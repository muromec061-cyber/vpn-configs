# VPN Configs

Личная VPN инфраструктура.

## Структура
-  — Chisel сервер для GitHub Codespaces (бесплатный туннель)
-  — скрипты установки и управления
-  — конфиг для Codespace
-  — автоматизация

## Как это работает
1. GitHub Codespace запускает Chisel сервер (бесплатно, 60ч/мес)
2. WSL на ПК подключается к Codespace через Chisel клиент
3. Через туннель доступны: подписка (порт 80) и VPN (WebSocket :8448)
4. Телефон подключается к публичному URL Codespace
